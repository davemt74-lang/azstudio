REVIEW DEFECTS FIXED BEFORE PACKAGING

  - Native FormData excluded disabled controls during Save draft; values are
    now captured before controls are disabled.
  - A matching fingerprint did not enforce curated candidate ranges at initial
    timeline creation; ranges are rechecked against current allowed candidates.
  - AI input omitted timestamped review notes; bounded in-range excerpts now
    accompany candidate labels and section notes.
  - AI runtime warnings described a different manual proposal; they now use the
    actual AI-selected clips, runtime and requirement deficits.
  - Malformed provider response shapes could emit PHP warnings; they now fail
    explicitly before iteration.
  - A late rejected AI request could overwrite newer local recovery; destroyed
    views no longer persist or alter its state.
  - A definitive invalid request left its input fields locked; editable fields
    now unlock while uncertain network receipts retain exact safe retry intent.
  - Canceling a proposal handoff falsely announced success; canceled handoffs
    leave status unchanged.
  - Unknown/too-short source duration could make coverage appear ready or block
    an unrelated valid named-cut save; usable counts and excluded bin handling
    now reflect actual editor eligibility.
  - Pending cut names could disappear during switching; naming drafts now save
    before navigation and participate in unsaved-change checks.
  - Source withdrawal between timeline and footage reads silently removed clips;
    the refreshed state now requires acknowledgment before rendering.
  - Successful lost write receipts could not recover after archival; recovery
    confirms existing success without performing a new closed-project write.
  - Withdrawing an unused bin source invalidated a valid rendered revision;
    export eligibility now checks the selected sources while retaining the exact
    immutable source-edit comparison.

SHORT INSTALLED ACCEPTANCE SEQUENCE

1. Back up the current installation and merge the deployment ZIP while retaining
   all storage/configuration/database/media. Sign in and hard-refresh.
2. Open Productions, add a small project and two coverage requirements. Assign
   one shot to a model and open one to eligible contributors.
3. On a real phone, accept/claim the work, record/upload, submit, and complete a
   requested retake. Verify only accepted footage counts in Director.
4. Mark usable sections, prepare a short first cut and save it as a named draft.
5. Adjust a trim/name, save another revision, view the old revision and restore
   or copy it. Confirm a second named cut retains independent edits.
6. Export, explicitly Save finished video, upload/capture a cover and use its
   editor return link. Confirm the exact saved revision opens.
7. Publish that finished version to Watch and inspect as a fan/signed-out visitor.
   Original takes, review notes and member appointments must remain private.
8. Test QR phone upload separately from optional live phone switching. Check
   USB/HDMI sources and the chosen microphone during manual/fixed/random changes.
9. If enabling AI, configure your provider and run one bounded real request;
   inspect/review the saved proposal before creating a new cut.

AZHOTTIE STUDIO v1.9.0 — MODEL-LED MEMBERSHIP & CASTING CRM

WHAT'S NEW

1. Public landing page redesigned as a bright, model-led AZHottie membership
   experience. Includes original light/angelic photoshoot hero, featured pathways
   to Watch, member events, private spa appointments, class registration,
   member signup, and a public model casting application. No paid subscription
   checkout has been added; do not represent memberships as paid entitlements.
2. Signed-in pages use a universal shared header, left sidebar and right-hand
   content canvas. The existing content, tools, recording controls and forms stay
   in the canvas. No nonfunctional AI chat bar has been inserted.
3. Public apply.php accepts private introductory applications from adults 18+.
   It does NOT create model accounts or grant model access. The casting team
   must explicitly approve applicants. Applications are rate-limited, require
   CSRF and contact opt-in, and reject invalid answers.
4. Private casting.php CRM shows leads, their original questionnaire answers,
   private reviewer notes, and stages: New, Contacted, Screening, Interview,
   Approved, Declined, Converted.
5. The same CRM has an editable public-questionnaire builder. Admins can add,
   delete, reorder and edit questions; add, delete and edit multiple-choice
   answers; change between single-choice, multi-choice, short text and long
   text; and choose required fields. A revision check prevents stale saves.
   Each application stores a complete snapshot of the questionnaire it saw.
6. Admin approval -> one-time invitation link -> invited account completes its
   model registration. Invitation tokens are 256-bit, stored only as hashes,
   expire in 7 days and become unusable after redemption. Existing member
   accounts must log in with the matching email; there is no password reset or
   automatic role elevation from a public application. Activated accounts receive
   model, fan and customer roles; a model profile is created or reused.
7. Six prebuilt editable private interview questionnaires remain included from
   the previous release, unaffected by public casting edits.

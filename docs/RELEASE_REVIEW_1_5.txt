V1.5 REVIEW CORRECTIONS

  - Failed settings loads could leave the shot-generation button enabled.
    Generation now stays disabled until settings recover, with a submit guard.
  - Reloading settings could not recover an outdated form token. The settings
    API now returns the current token, and the UI refreshes it before retrying.
  - Credential migration moves the legacy key and clears its duplicate in the
    same transaction. Replay cannot restore a key that was later removed.
  - Provider/model selections are fixed in the original job and saved receipt,
    so later settings edits cannot reroute a retry or relabel an old proposal.
  - Model access checks are labeled separately from actual generation support.
    No paid request or silent fallback is triggered by testing a key.

The earlier Director/editor review corrections remain covered by the full
regression matrix and are preserved in RELEASE_REVIEW_1_4.txt.

SHORT INSTALLED ACCEPTANCE SEQUENCE

1. Back up the current installation and merge the deployment ZIP while retaining
   all storage/configuration/database/media. Sign in and hard-refresh.
2. Open Productions, add a small project and two coverage requirements. Assign
   one shot to a model and open one to eligible contributors.
3. On a real phone, accept/claim the work, record/upload, submit, and complete a
   requested retake. Verify only accepted footage counts in Director.
4. Mark usable sections, prepare a short first cut and save it as a named draft.
5. Adjust a trim/name, save another revision, view the old revision and restore
   or copy it. Confirm a second named cut retains independent edits.
6. Export, explicitly Save finished video, upload/capture a cover and use its
   editor return link. Confirm the exact saved revision opens.
7. Publish that finished version to Watch and inspect as a fan/signed-out visitor.
   Original takes, review notes and member appointments must remain private.
8. Test QR phone upload separately from optional live phone switching. Check
   USB/HDMI sources and the chosen microphone during manual/fixed/random changes.
9. If enabling AI, open Admin, save keys, check model access, select a model
   and provider for each task, then enable. Run one bounded real shot proposal
   and edit proposal using each configured provider and inspect the results
   before creating shots/cuts. Confirm billing and model access in your accounts.

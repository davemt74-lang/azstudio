Phone connection architecture

The interview-scoped approval/capability and WebRTC offer/answer flow in this
release adapts the user's Lucky phone-pairing and recording-camera reference
code. AZHottie uses its own authenticated host endpoints, approved phone
capabilities, upload store, and interview records. Lucky credentials,
configuration, databases, and user data are not included in this package.

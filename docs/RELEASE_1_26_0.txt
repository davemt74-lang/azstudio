AZHOTTIE STUDIO v1.26.0 — CASTING & ONBOARDING SPECIALIST
21 November 2026

Scope: integrate existing Casting CRM, private invitations, model profiles,
production eligibility, Agent Brain, Agent Chat, History, and the v1.24 private
hourly follow-through cron. No new standalone AI assistant.

Implemented sections and independent local quality gates
-------------------------------------------------------
1. Applications and pipeline: Admin Casting CRM displays required-answer
   completeness, applicant-provided experience and availability, age of the
   current stage, and source-backed follow-up rules. Personal answers are
   available ONLY in the authorized CRM. New applications generate admin
   history/notifications. Revision-checked admin actions can advance just
   new -> contacted -> screening -> interview; all approval, rejection and
   invitation issuance still require the original CRM workflow.
2. Onboarding: Converted active model accounts have four factual checkboxes:
   active model profile bio, general availability, admin-confirmed studio
   orientation, and admin-confirmed production readiness. Models see only
   their own progress. Admins can confirm/reopen attested steps with CSRF and
   role checking. Completion is not a substitute for production-specific
   permissions or affirmative participant consent.
3. Production matching: Suggestions are drawn only from the existing
   eligible production roster and models with ALL onboarding steps complete.
   The agent does NOT automatically assign models, infer availability from
   historic records, or make aptitude/appearance judgments. Admins check
   current availability and suitability in the existing production workflow.
4. Proactive follow-through: The private existing hourly cron examines
   new applications older than 24 hours, contacted/screening/interview
   stages unchanged for seven days, approved applications lacking active
   invitations, invitations expiring within 24 hours, and converted accounts
   still incomplete after three days. Durable unique delivery fingerprints,
   per-recipient notifications, locks, bounded scans and private receipts
   prevent routine duplicate alerts. Models also receive their own
   incomplete-onboarding reminder, not applicant data.
5. Brain and Chat: The shared Brain displays verified casting counts,
   follow-up cards, onboarding checklists and safe stage controls. The
   existing Agent Chat displays a live read-only casting companion and a
   ready-to-send question. Both use the same structured report:
   Key findings / Actions & follow-ups / Open questions / Next step /
   Questions for you. Only aggregate, anonymized casting summaries enter
   external AI provider context, without applicants' names, contact
   information, answers, notes, private invitation tokens or media.
   The existing Chat has no LLM action tools. Human-confirmed HTTP actions
   are separate authenticated requests with CSRF and authorization.
6. Privacy, roles and audit: Model scope is exclusively the current account;
   CRM and early stage actions require admin. One recipient cannot read or
   acknowledge another's activity. Real stage/confirmation mutations are
   written into the existing History ledger; reminders carry an Agent
   attribution, not a fabricated model action. No external outreach is sent.

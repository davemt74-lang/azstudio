# AZHottie Studio v1.41.0 — Live shopping analytics & Admin Command Center

## Implementation

- Full responsive, admin-only Studio Command Center replaces the old admin homepage.
- Six live scorecards: 30-day signed Stripe product net, separately staff-recorded cash net, Stripe-confirmed live-attributed net, new casting applications, pending video submissions, and 30-day video play starts.
- Action queue for financial provider reconciliation, unreviewed casting applications, pending creator videos, unverified manual orders, settlement approval, and creator promotions, with deep links to existing workspaces.
- Casting CRM shows recent open model application profiles, city, status and screening dates. "Resumes" refers to existing applicant screening records; this does not claim a PDF résumé upload feature.
- Video review uses existing model_videos state; fixes pending_review being miscounted as zero pending.
- 14-day profile view / video play / live product impression chart, plus 30-day completion, watch-time, and CTA totals. These are events, not distinct people.
- Live Director displays selected product, approved creator, session-bounded product view and button-tap counts, Stripe checkouts/confirmed net, with cash and commissions kept separately.
- Admin-only data access; authorized production editors see only their permitted live tools.

## Safety and attribution

- Engagement events are bound on the server to the **currently featured active live product and approved creator promotion**; clients cannot supply the attribution IDs.
- Impression occurs only when the product is visible in the foreground for about 1.2 seconds. No viewer identity, IP, browser fingerprint or page history is persisted. A single browser session records at most one view and one CTA tap per active spotlight each 30 minutes.
- Signed Stripe payment events, administrator-attested external seller orders and recorded cash transactions are not combined in a false "verified revenue" total. Commission figures are estimates, not paid balances.
- No refund, EasyPost label purchase, Stripe Connect transfer, payout, credit card charge or production mode enablement is added by dashboard tracking.
- Live financial actions remain disabled by default and require separate hosted TEST verification and explicit staff configuration.

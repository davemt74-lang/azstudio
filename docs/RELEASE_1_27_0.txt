AZHottie Studio v1.27.0 — Calendar & Scheduling Specialist

Components
- Authenticated unified read model built from existing schedule and Work records.
- Private model weekly availability and unavailable windows; revision-gated edits.
- Administrator-only active-production roster matching for a proposed date/time.
- Account-scoped conflict detection for bookings/events; deadlines are informational.
- In-app 24-hour appointment and registered-event reminders through existing private cron.
- Agent Chat / Brain / History integration, no autonomous booking or assignments.
- Light responsive calendar panel; no nested scrolling.

Security
- Only a model can edit their own availability or blocked dates.
- Only production owners can query their own roster matching.
- Only fully onboarded eligible models participate in matching.
- Missing availability is unknown, never presumed available.
- All POSTs use the canonical CSRF/session/shared mutation lock.
- External AI receives aggregate schedule counts and event types/timestamps only,
  with no personal name, booking notes, questionnaire or media.
- In-app reminders are idempotent per recipient, item, rule and start time.

AZHottie Studio v1.31.0 — Verified Commerce & Affiliate Attribution

- Optional Stripe-hosted Checkout alongside existing external-seller links. Stripe `amount_subtotal` is reconciled to the merchant product-price snapshot; `amount_total` and tax/shipping/discount detail are checked and stored separately so creator commissions do not include sales tax. Server-side keys: AZH_STRIPE_SECRET_KEY, AZH_STRIPE_WEBHOOK_SECRET and AZH_PUBLIC_BASE_URL (trusted HTTPS origin). Alternatively configure in protected storage/config.php['commerce'] as stripe_secret_key, stripe_webhook_secret and public_base_url. Live keys require explicit AZH_STRIPE_ALLOW_LIVE=1 (or private stripe_allow_live=true). Disabled by default without valid settings.
- Register the Stripe webhook endpoint https://YOUR-SITE/commerce-stripe-webhook.php for checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.expired, charge.refunded, charge.dispute.created and charge.dispute.closed. Use the signing secret for that endpoint. No API credentials are stored in the repo or exposed to buyers.
- POST checkout uses browser CSRF, IP throttle, immutable server price/commission snapshots and Stripe idempotency. A success redirect NEVER marks an order paid; only signed Stripe events can create provider-verified paid orders. Verify raw event body, 5-minute signature tolerance, exact attempt ID, amount, USD currency, session and test/live mode. Retry and duplicate events cannot create repeat orders.
- Creator attribution is only from approved and current published videos or explicitly selected live promotions, with snapshot rate at checkout creation. Existing external seller links are not provably attributed.
- Refunds reduce verified net revenue and pending creator commission estimates. Disputes hold the commission. No automated transfer or creator payout is attempted.
- Commerce Analytics separates signed Stripe results from administrator-attested manual orders. Reports include 30-day net USD, refunds, estimated commissions, paid checkout sessions per started session (not visitor conversion), top products and attribution channels. Models see only their own attributed amounts.
- Public Shop, creator Watch and the Live viewer offer Stripe-hosted checkout only for an eligible configured product. Live Director allows explicit creator association; all current account/consent/revision checks still apply.
- Existing Agent bell, History, Brain and Agent Chat receive provider-verified commerce events through the same outbox. No second agent or notification store is created. Scheduled order review remains on existing cron.
- Schema migration 36→37 is replay-safe, including interrupted MySQL column upgrades. Back up the database and private storage first. Preserve uploaded media/config files. Do not rerun install.php.
- This release does NOT automate fulfillment, tax compliance, refunds initiated from AZHottie, payment disputes resolution, or payouts. Shipping is collected through Stripe (US only by default). Merchant must validate commercial requirements and Stripe keys on their own host before live sales.
- Source-only 10/10 gate: all final-commit CI tests pass (PHP/SQLite lifecycle, signatures, retries, role isolation, browser layouts, JS regressions, deploy ZIP). Production 10/10 requires hosted MySQL migration, real TEST Stripe payment/refund/webhook replay and fulfillment/tax checks.
